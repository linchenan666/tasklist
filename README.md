# 任务清单网站 TaskList

一个**纯本地、永久免费、离线可用**的全功能任务清单应用。

✅ 无需账号 · ✅ 无需联网 · ✅ 无需服务器 · ✅ 绝不扣费

## 特性

- **完全离线**:数据存在浏览器本地,刷新/关闭都保留,断网照常用
- **永久免费**:没有任何付费、订阅、广告、跳转购买
- **全功能**:列表/看板/日历/四象限视图、子任务、重复任务、提醒、番茄钟、统计图表、成就徽章、游戏化
- **撤销 / 重做** + **返回 / 前进**
- **自动保存**,退出后数据不丢
- **深色 / 浅色 / 跟随系统**,手机/平板/电脑自适应
- **可装到主屏幕**(PWA,需 http/https 访问)

## 怎么用

### 方式 1:直接双击打开(最快)
双击 `index.html`,浏览器打开即用。

### 方式 2:本地服务器(推荐,功能最完整)
在 `task-list` 文件夹里运行:

```
node server.js
```

然后浏览器打开 **http://localhost:4173**

> 方式 2 走 http/https,才能启用 PWA「添加到主屏幕」和离线缓存。

## 跨设备同步(免费、手动)

数据存在**每台设备各自的浏览器**里。要让手机/平板/电脑数据互通:

1. 在设备 A 点左下角「**导出**」→ 得到 `任务清单备份-日期.json`
2. 把文件发到设备 B(微信文件传输 / 数据线)
3. 在设备 B 点「**导入**」→ 选择该文件

数据就互通了(手机改完同步回电脑同理)。

> 说明:这是「**手动同步**」。自动同步需要云服务器,而国内云都要花钱或实名认证。为了坚持**永久免费**,所以采用这种零成本方式。

## 快捷键

| 键 | 功能 |
|---|---|
| `N` | 新建任务 |
| `/` | 聚焦搜索 |
| `1`–`7` | 切换视图(我的今天/今天/即将/逾期/收件箱/已完成/全部) |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 |
| `Alt+←` / `Alt+→` | 返回 / 前进界面 |
| `?` | 快捷键面板 |
| `Esc` | 关闭弹窗 |

## 自然语言快速添加

在顶部输入框直接输入,例如:
- `明天下午3点买牛奶 #购物 !高`
- `周五交作业 !p1`
- `3天后复习高数 晚上8点`

自动解析标题、日期、时间、标签、优先级。

## 数据说明

- 数据保存在浏览器 **localStorage**(存在你的电脑/手机里)
- **清除浏览器数据**会清空任务;重要数据建议定期用「导出」备份一份
